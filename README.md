# 8秒前の自分 / EIGHT SECONDS

四方向移動だけで遊べる、過去の自分とのサバイバルゲーム。HTML / CSS / JavaScriptのみで動作し、ビルドや外部CDNは不要です。

公開予定URL: https://megaminxkr.github.io/8_seconds/

## ルール

- 矢印キー / WASD、画面の方向ボタン、またはフィールドのスワイプで移動します。斜め移動はありません。複数キーを押した場合は最後に押した方向を優先します。
- 8秒ごとに敵（ECHO）が1体増えます。1体目は8秒前、2体目は16秒前、3体目は24秒前…のプレイヤー位置を再現します。敵はそのまま軌跡をたどり続け、8秒の区間をループする方式ではありません。
- 敵は開始地点から出現します。直前の1.5秒は予告を表示し、出現後0.75秒間は半透明で接触判定がありません。
- 敵への接触でゲームオーバー。壁にぶつかっても終了しません。
- 得点 = コイン枚数 × 100 + 生存した整数秒 × 10。
- Space / Esc / 一時停止ボタンで中断・再開。タブ切り替えやウィンドウのフォーカス喪失でも自動停止します。
- サウンドは初期状態でOFF。ベストスコアは同じブラウザのlocalStorageに保存します。端末間の同期はありません。保存が禁止されていてもプレイできます。

## GitHub Pagesへの公開

このリポジトリの **Settings → Pages → Build and deployment** で次を指定してください。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

保存後にGitHubのデプロイが完了すると、上記URLで遊べます。すべてのアセットを相対パスで参照しているため、`/8_seconds/`配下で動作します。

## ローカル実行・テスト

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く

npm test
```

ES Modulesを使っているため、HTMLファイルの直接ダブルクリックではなくHTTPサーバー経由で開いてください。テストにはNode.js 18以降を使用します。npm installは不要です。

## 構成と検証

- `engine.js`: 60Hz固定刻みのゲームロジック、軌跡再生、衝突、コイン、得点。
- `game.js`: Canvas描画、キーボード・タッチ入力、画面状態、音声、記録保存。
- `style.css` / `index.html`: レスポンシブ画面。
- `tests/engine.test.js`: 出現時刻、独立した遅延再生、出現直後の猶予、衝突、移動制限、得点、コイン再配置、初期化の自動テスト。
- `tests/ui.test.js`: 実際のUI制御コードを、DOMの代替実装と制御可能な時計で実行。一時停止、再開、フォーカス喪失、入力優先順位、タッチ解除、保存失敗、リトライを検証。

自動テストは計15件。検証範囲と制限は `TESTING.md` に記載しています。

ゲーム時間はシミュレーションのフレーム数から算出します。0.5秒を超える描画中断時には自動停止し、見えない間にゲームオーバーになるのを防ぎます。プレイ中の座標履歴はメモリに保持し、再挑戦時に破棄します。
